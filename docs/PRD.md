## 1. 产品概述

### 1.1 产品定位

Ketches 是一个面向企业级的云原生应用平台，旨在简化 Kubernetes 环境下的应用构建、部署和管理流程。通过提供直观的用户界面和完善的 API 接口，帮助开发团队快速将应用部署到多个 Kubernetes 集群，并提供全面的应用生命周期管理能力。

### 1.2 目标用户

| 用户角色 | 描述 |
| ------- | ---- |
| **平台管理员 (Admin)** | 负责平台整体管理，包括集群接入、用户管理、系统配置等 |
| **项目负责人 (Owner)** | 负责项目管理，包括环境规划、成员管理、应用审批等 |
| **开发人员 (Developer)** | 负责应用开发和部署，包括创建应用、配置环境变量、查看日志等 |
| **只读用户 (Viewer)** | 仅查看项目和应用信息，无修改权限 |

### 1.3 产品目标

1. **降低 Kubernetes 使用门槛**：无需深入了解 K8s 概念即可完成应用部署
2. **多集群统一管理**：支持同时管理多个 Kubernetes 集群
3. **完善的权限体系**：基于角色的访问控制，支持项目级别权限隔离
4. **全生命周期管理**：从应用创建到运维监控的完整管理能力

## 5. 数据模型

### 5.1 核心实体关系

```txt
User (用户)
    │
    ├── 1:N ──▶ ProjectMember (项目成员) ◀── N:1 ── Project (项目)
    │                                                    │
    │                                                    │
    └──────────────────────────────────────────────────  │
                                                         │
                                                    1:N  │
                                                         ▼
                                                    Env (环境) ◀── N:1 ── Cluster (集群)
                                                         │
                                                    1:N  │
                                                         ▼
                                                    App (应用)
                                                         │
                    ┌────────────┬────────────┬──────────┼──────────┬────────────┐
                    │            │            │          │          │            │
                    ▼            ▼            ▼          ▼          ▼            ▼
              AppEnvVar    AppVolume   AppGateway   AppProbe  AppConfigFile  AppSchedulingRule
```

### 5.2 实体属性概要

| 实体 | 关键属性 |
| ---- | ------- |
| User | username, email, password, role, fullname |
| Cluster | slug, displayName, kubeConfig, gatewayHost, enabled |
| Project | slug, displayName, description |
| Env | slug, displayName, clusterID, clusterNamespace |
| App | slug, displayName, appType, containerImage, replicas, status |
| AppEnvVar | key, value |
| AppVolume | slug, mountPath, volumeType, capacity |
| AppGateway | port, protocol, domain, path, exposed |
| AppProbe | type, probeMode, enabled |
| AppConfigFile | slug, mountPath, content, fileMode |
| AppSchedulingRule | ruleType, nodeName, nodeSelector, tolerations |
